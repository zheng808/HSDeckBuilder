# Project-wide rules

- **Single source of truth for domain logic is `shared/`.** Deck legality (`validateDeck`, `canAddCard`), stats, and deck codes live in `shared/src`. Never re-implement a rule in the server or client; import it.
- **Change the contract in this order:** `shared/src/schemas.ts` (zod) → server route → `server/src/__tests__/api.test.ts` → `docs/API.md` → `client/src/api/hooks.ts`.
- **Error envelope is fixed:** `{ error: { code, message, issues? } }`. Status codes: 400 schema, 401 no owner token, 403 wrong owner, 404 missing/private, 422 deck-rule violation.
- **Ownership model:** anonymous owner token in the `x-owner-token` header, stored hashed. Do not add accounts without discussing it; see docs/ARCHITECTURE.md "Path to real auth".
- **Verification before claiming done:** `npm run check` (typecheck + tests + client build) must pass. Say so explicitly, with output, if anything fails.
- Card data in `server/data/*.json` is generated by `npm run seed:cards`; never hand-edit.
- Prettier formats on save via a hook; do not fight its style. TypeScript is strict with `noUncheckedIndexedAccess`.
